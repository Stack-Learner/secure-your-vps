# Configure Dokploy Traffic Routing
> Traefik is a reverse proxy that handles HTTPS, routing, and security for your applications. It sits between the internet and your applications, managing SSL certificates and directing traffic.

## Step 1: Add Security Middleware

```yaml
http:
  middlewares:
    security-headers:
      headers:
        stsSeconds: 31536000
        stsIncludeSubdomains: true
        stsPreload: true
        forceSTSHeader: true
        frameDeny: true
        contentTypeNosniff: true
        browserXssFilter: true
        referrerPolicy: "strict-origin-when-cross-origin"
        contentSecurityPolicy: "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'"
        customResponseHeaders:
          X-Robots-Tag: "noindex, nofollow"
```
**Explanation:**
- **stsSeconds**: Enables HTTP Strict Transport Security (HSTS) for 1 year
- **frameDeny**: Prevents clickjacking attacks by blocking iframe embedding
- **contentTypeNosniff**: Prevents MIME type sniffing by browsers
- **browserXssFilter**: Enables XSS protection in browsers
- **referrerPolicy**: Controls how much referrer information is sent
- **contentSecurityPolicy**: Restricts resource loading to approved sources
- **X-Robots-Tag**: Prevents search engine indexing of sensitive pages


## Step 2: Add Rate Limiting Middleware

```yaml
http:
  middlewares:
    rate-limit:
      rateLimit:
        average: 100
        burst: 50
        period: 1m
```
**Explanation:**
- **average: 100**: Allows 100 requests per minute on average
- **burst: 50**: Allows up to 50 additional requests during traffic spikes
- **period: 1m**: Rate limit resets every minute
- Protects against DDoS attacks and API abuse
- Prevents server overload from excessive requests


## Step 3: Add the above middleware to the Dokploy dashboard router
```yaml
http:
  routers:
    dokploy-dashboard:
      rule: "Host(`deploy.yourcompany.com`)"
      service: "dokploy"
      entryPoints:
        - "websecure"
      middlewares:
        - "security-headers"
        - "rate-limit"
      tls:
        certResolver: "letsencrypt"
```
