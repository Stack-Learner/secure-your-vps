# Solve the github autodeploy issue
After block the 3000 port the github autodeploy will not work. To solve this we have two solution
1. Use github webhook for every repository
2. Allow 3000 port for the Github webhook

## Solution 1: Use github webhook for every repository
- To to yoru dokploy app deployment section. 
- Copy the webhook url.
- Go to your github repository.
- Add a webhook with the webhook url you copied.


## Solution 2: Allow 3000 port for the Github webhook
```bash
sudo iptables -I DOCKER-USER -p tcp --dport 3000 -s 192.30.252.0/22 -j ACCEPT
sudo iptables -I DOCKER-USER -p tcp --dport 3000 -s 185.199.108.0/22 -j ACCEPT  
sudo iptables -I DOCKER-USER -p tcp --dport 3000 -s 140.82.112.0/20 -j ACCEPT
sudo iptables -A DOCKER-USER -p tcp --dport 3000 -j DROP
```
