# VPS Setup Guide
> This guide will help you set up a VPS instance for Dokploy. 


## Step 1: Create VPS
```bash
For Dokploy you need a VPS instance with the following specifications:
RAM: 4 GB to 8 GB+.
CPU: 2 to 4 vCPUs.
Storage: 40 GB to 160 GB+ SSD.
```


## Step 2: Install Necessary Packages
```bash
# Login to the vps
ssh hmnayem@163.61.156.180
# or
ssh -o ServerAliveInterval=60 hmnayem@163.61.156.180

 # Switch to root user
sudo -i

# Update and upgrade system packages
apt update && apt upgrade -y 

# Install necessary packages
apt install ufw fail2ban curl wget -y
```
**Explanation:**
- **ufw**: Uncomplicated Firewall - manages firewall rules for server security
- **fail2ban**: Protects against brute-force attacks by monitoring log files and banning malicious IPs after multiple failed login attempts
- **curl**: Command-line tool for transferring data with URLs
- **wget**: Command-line tool for downloading files from the web 


## Step 3: Create User and Set Password
```bash
# Create a user
sudo adduser rasel
```
## Step 4: Add User Administrator Groups
Groups are a way to manage user permissions and access control on Linux systems. They allow multiple users to share the same access rights to files, directories, and system resources.

```bash
# Show groups the current user belongs to
groups
# or see all system groups available
getent group | cut -d: -f1
# or check specific user's groups
groups hmnayem
# Add user to both sudo and docker groups in a single command
usermod -aG sudo rasel
usermod -aG docker rasel

# or
usermod -aG sudo,docker hmnayem
```
**Explanation:**
- **sudo group**: Grants administrator privileges, allowing the user to execute commands with root access using `sudo`
- **docker group**: Allows the user to run Docker commands without prefixing with `sudo`, which is required for Dokploy deployment workflow
