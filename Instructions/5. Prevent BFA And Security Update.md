# Prevent Brute Force Attacks & Enable Automatic Security Updates
> This guide helps you protect your VPS from brute force attacks and set up automatic security updates.

## Prevent Brute Force Attacks
Fail2ban automatically bans IPs that have too many failed login attempts to prevent brute force attacks.
```bash
# Install Fail2ban
apt install fail2ban -y

# Enable and start the service
systemctl enable fail2ban
systemctl start fail2ban

# Check status
systemctl status fail2ban
```
**Explanation:**
- Monitors SSH login attempts for suspicious activity
- Automatically bans IPs with repeated failed login attempts
- Protects your SSH service from automated brute force attacks
- Reduces server load from malicious login attempts


## Enable Automatic Security Updates
Automatic security updates ensure your system is protected against known vulnerabilities without manual intervention.
```bash
# Install unattended-upgrades
apt install unattended-upgrades -y

# Configure automatic updates
dpkg-reconfigure -plow unattended-upgrades
```
**Explanation:**
- Automatically installs security patches and updates
- Reduces manual maintenance and system administration overhead
- Keeps system protected against known vulnerabilities
- Ensures critical security fixes are applied promptly
