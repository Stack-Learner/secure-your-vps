# Configure Cloudflare Zero Trust
> This guide helps you set up Cloudflare Zero Trust tunnel for secure access to your Dokploy dashboard with identity provider integration. 


## Create Cloudflare tunnel

1. Create a tunnel from Networks-> Tunnels/Mesh 
2. Give the tunnel a name
3. Select the Docker container and copy only the token. 
4. Go to the dokploy dashboard and create a Cloudflared service from the template.
5. Override the Cloudflared service docker compose with this: 

```sh
services:
  cloudflared:
    image: 'cloudflare/cloudflared:latest'
    environment:
      # Don't forget to set this in your Dokploy Environment
      - 'TUNNEL_TOKEN=${CLOUDFLARE_TUNNEL_TOKEN:?}'
    networks:
      - dokploy-network
    restart: unless-stopped
    command: [
      "tunnel",
      "--no-autoupdate",
      "run"
    ]

networks:
  dokploy-network:
    external: true

```

6. Past the token in the environment variable.
7. Give the subdomain (e.g: dokploy)
8. Select the Domain (e.g: theremotegang.com)
9. In the service Section . Select HTTP and URL : dokploy:3000

## Create Identity Provider
1. Go to the Integration/Identity Provider
2. Add you Identity Provider (e.g: Google, One-time-pin)

## Create Application
1. Go to the Access Controls -> Applications
2. Create new Application
3. In the public hostname section give the subdomain (e.g: dokploy) and select the domain (e.g: theremotegang.com)
3. Create a access Policy
4. Give the policy a Name :Allow User Access , Action: Allow
5. In the Policy Rules Create a Include Rule and select Emails and value (eg: your-email@example.com)
6. Save the policy and assign it to the application.( by default it will assing automatically if you crate the policy from the application)
